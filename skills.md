# Project skill guide

## Reproducible comparison

Location: [.agents/skills/reproducible-comparison/SKILL.md](.agents/skills/reproducible-comparison/SKILL.md)

Use this skill for SPHEREx observation selection, cutout preparation, image registration/rendering, comparison identity and persistence, exact replay, or migration of retained evidence. Invoke it as `$reproducible-comparison` where the agent supports project skill discovery; otherwise read the linked file directly.

The skill covers explicit configuration, provenance, deterministic identity, immutable artifacts, and verification before scientific comparison.

The archive owner uses it for frame preparation and durable manifests. Viewer and findings owners use the relevant parts when consuming or restoring evidence. Ordinary layout, discussion styling, and documentation edits do not require running an archive experiment.

`AGENTS.md` holds shared working and evidence-reporting rules. `spherex-project-brief.md` and `spherex-agent-handoffs.md` remain the product and implementation contract. This guide does not introduce additional features or replace that contract.
